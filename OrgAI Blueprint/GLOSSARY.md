# 术语表

全项目统一用词。正文中术语第一次出现时给出中文全称和英文缩写，并在此登记。

## 格式说明

- 每条术语一行，按表格格式填写：术语｜英文｜一句话解释｜首次出现章节。
- 一句话解释按 [STYLE_GUIDE.md](STYLE_GUIDE.md) 第 1 节"一句话本质"的风格写：讲清它是什么、本质是什么，不出现公式和未解释的术语。
- "首次出现章节"写章节编号；正文定稿后按实际首次出现位置核对。
- 同一概念只用一个中文术语，别称写在解释中。

## 术语

| 术语 | 英文 | 一句话解释 | 首次出现章节 |
|---|---|---|---|
| 大语言模型 | Large Language Model, LLM | 在大量数据上训练、根据上下文预测和生成语言的模型，可用于问答、整理和生成内容，但输出不保证正确。 | 01 |
| 提示工程 | Prompt Engineering | 通过精心设计给大模型的指令和示例来改善输出，本质是把任务"交代清楚"，不改变模型本身。 | 01 |
| 检索增强生成 | Retrieval-Augmented Generation, RAG | 先从获准使用的资料中检索相关内容，再让模型结合资料生成回答，本质是把外部信息引入生成过程。 | 01 |
| 微调 | Fine-tuning | 用组织自己的样例数据对已有模型再训练一轮，本质是让通用模型经过"岗前培训"，掌握特定的表达方式和做事习惯。 | 01 |
| 智能体 | AI Agent | 根据目标和环境信息选择步骤并可调用工具的 AI 系统，本质是将模型判断与外部行动连接，能做什么取决于权限和设计。 | 01 |
| 机器人流程自动化 | Robotic Process Automation, RPA | 按预先写好的固定规则模仿人在电脑上点击和录入的软件，本质是一台照章执行、不会变通的"操作录像回放机"。 | 01 |
| 向量数据库 | Vector Database | 存储和检索数字向量的数据库，可按表示之间的相似度寻找资料，也可与关键词检索等方法配合。 | 01 |
| 知识图谱 | Knowledge Graph | 把人、机构、产品、事件等实体及它们之间的关系结构化存储起来，本质是一张可以查询和推理的"关系网"。 | 01 |
| 多模态 | Multimodal | 能同时处理文字、图片、语音、视频等多种类型信息的 AI 能力，本质是让 AI 不只会读字，也能看和听。 | 01 |
| 推理 | Inference | 训练好的模型接收输入并给出结果的过程，本质是模型"上岗干活"的环节，日常使用成本主要发生在这里。 | 01 |
| 量化 | Quantization | 用较低精度的数字表示模型参数或计算值，可能减少存储和计算开销，实际速度和效果变化需在目标环境中测试。 | 01 |
| 蒸馏 | Knowledge Distillation | 让小模型模仿大模型的输出来学习，本质是"老师带徒弟"，用更小、更便宜的模型完成特定任务。 | 01 |
| 私有化部署 | Private Deployment | 在组织控制或专属的环境中部署模型和应用，以获得更直接的控制；数据是否出域取决于实际接口、日志和运维设计。 | 01 |
| 幻觉 | Hallucination | 模型生成与事实不符或缺乏依据的内容，表现可能包括错误引用、虚构信息或不受资料支持的回答。 | 01 |
| Token | Token | 模型处理文本时使用的分词单位，一个单位与字或词的对应关系因语言和分词方式而异，也常用于计算调用量。 | 01 |
| 概念验证 | Proof of Concept, POC | 用小范围、低成本的试验验证某项技术能否解决某个问题，本质是正式投入前的"可行性试水"。 | 04 |
| 最小可行产品 | Minimum Viable Product, MVP | 只包含核心功能、能交给真实用户使用的第一个版本，本质是用最小投入换取真实使用反馈。 | 04 |
| 总拥有成本 | Total Cost of Ownership, TCO | 一项系统在整个使用周期内的全部成本，包括采购、实施、运维、人员和升级，本质是"算总账"而不只看买价。 | 06 |
| 投资回报率 | Return on Investment, ROI | 收益减去成本后与成本的比值，本质是回答每投入一元对应多少净收益。 | 06 |

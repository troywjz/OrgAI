# 来源登记表

所有数字、案例、市场判断和法规引用必须在此登记，正文用 `[S编号]` 标注。

## 登记规则

1. 编号从 S001 起顺序递增，编号一经分配不再改动或复用；来源失效时在"核实状态"中标注，不删除行。
2. 行业报告写明发布机构和年份；法规写明发布机关和最新版本年份。
3. 时效敏感的数据和政策应在正文注明时间并按主题复核；基础理论文献注明原始年份，不因年限自动失效。
4. 链接优先使用发布机构官方页面；无公开链接的来源不得登记。
5. "用于哪章"写章节编号，可多项，例如"01, 06"。
6. 核实状态取值：待核实、已核实（注明核实日期）、已失效。只有"已核实"的来源可用于定稿正文和 PPT。
7. 不登记涉密信息、未公开的客户数据或个人信息。

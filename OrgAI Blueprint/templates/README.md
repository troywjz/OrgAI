# 模板

新增技术、场景、案例、评估或 PPT 页面时，从本目录复制对应模板，删除 HTML 注释中的填写说明后提交。所有模板遵守 [STYLE_GUIDE.md](../STYLE_GUIDE.md)。

| 模板 | 用途 | 使用位置 |
|---|---|---|
| [tech-card.md](tech-card.md) | 技术卡：讲清一项技术的本质、价值、与相近技术的差异和选择规则 | [01 AI 技术全景](../docs/01-tech-landscape/README.md) |
| [scenario-card.md](scenario-card.md) | 场景卡：描述一个可立项的应用场景及其优先级评分 | [03 组织应用场景](../docs/03-org-scenarios/README.md) |
| [case-card.md](case-card.md) | 案例卡：按统一格式记录一个公开可核实的应用案例 | [05 案例](../docs/05-cases/README.md) |
| [evaluation-sheet.md](evaluation-sheet.md) | 效果评估表：记录基线、目标、实际指标和 ROI | [06 效果评估](../docs/06-evaluation/README.md) |
| [ppt-page-brief.md](ppt-page-brief.md) | PPT 单页策划：从正文提炼一页 PPT 的结论与呈现方式 | [slides/](../slides/README.md) |

## 通用规则

- 所有数字和案例须有来源，登记到 [references/sources.md](../references/sources.md)，正文用 `[S编号]` 标注。
- 没有可靠数字时写“待测量”或“未披露”；确需估算时说明假设、依据和不确定性。
- 尚未填写的部分保留 `> TODO` 标记。

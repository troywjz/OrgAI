# PPT 规划

PPT 从 Markdown 正文派生，不出现正文没有的结论（见 [STYLE_GUIDE.md](../STYLE_GUIDE.md) 第 6 节）。各章 README 末尾的"PPT 要点"是 PPT 内容的主要来源。

## 生成流程

1. Markdown 正文定稿。
2. 用 [templates/ppt-page-brief.md](../templates/ppt-page-brief.md) 为每页做单页策划，确定结论式标题、核心信息、支撑要点、视觉形式和数据来源。
3. 按策划生成 .pptx，成品放在本目录下。

## 计划的三套 PPT

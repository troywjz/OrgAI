# 03 组织应用场景

## 本章目标

本章回答“按职能、行业、组织类型，哪些场景值得做”。本章将第 02 章的应用形态落到业务环节，先审查风险门槛，再比较价值和可行性，帮助组织选出第一批可验证的试点场景。

## 主要读者

业务负责人；决策者用于确认优先级。

每个场景使用 [templates/scenario-card.md](../../templates/scenario-card.md) 场景卡模板，在"所需技术"栏链接第 01 章技术卡。

## 不同组织类型的差异

- 企业：场景价值以降本、增收、提效为主要衡量方式。
- 【政府】场景价值可考虑服务效能、公平性和群众满意度；风险门槛需结合具体数据、用途和适用要求审查。
- 【事业单位】需关注编制与考核机制是否支持场景落地，以及专业人员的参与意愿。
- 【非营利】可行性评分需重点考虑资金和技术人员约束，优先选择投入小、见效快的场景。

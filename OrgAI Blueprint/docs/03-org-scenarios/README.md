# 03 组织应用场景

## 本章目标

本章回答"按职能、行业、组织类型，哪些场景值得做"。本章把第 02 章的应用形态落到具体业务环节，形成可直接拿去讨论立项的场景清单，并提供一套"价值 × 可行性 × 风险"的优先级评估方法，帮助组织从众多候选场景中选出第一批要做的。

## 主要读者

业务负责人；决策者用于确认优先级。

## 不同组织类型的差异

- 企业：场景价值以降本、增收、提效为主要衡量方式。
- 【政府】场景价值以服务效能和群众满意度衡量，风险评分需加重数据合规和公平性权重。
- 【事业单位】需关注编制与考核机制是否支持场景落地，以及专业人员的参与意愿。
- 【非营利】可行性评分需重点考虑资金和技术人员约束，优先选择投入小、见效快的场景。

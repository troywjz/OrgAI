# 场景卡：从业务文件中抽取字段并辅助分流

> **策划/合成示意**：用于组织评审方案，不是实际客户案例、实测结果或已设定目标。适用性、基线、数值及合规要求均须由采用组织核验。

## 基本信息

| 项目 | 内容 |
|---|---|
| 场景名称 | 从业务文件中抽取字段并辅助分流 |
| 所属职能 | 财务、采购、行政、人力、客服、运营及业务受理 |
| 所属行业 | 跨行业 |
| 适用组织类型 | 企业、政府、事业单位、非营利组织 |
| 应用形态 | 文档处理与审核；可组合规则校验、内容生成和流程自动化 |

## 业务流程与基线

组织收到票据、表单、合同、申请或来函后，工作人员登记文件、识别字段、检查完整性、查询规则并分流给审核人。基线须按一种明确文件类型建立，记录来源和版式、语言、扫描质量、字段字典、现行录入/复核步骤及例外处理。基线数值**待测**：每份处理时间、字段级正确/漏抽率、漏检与误报、人工复核比例、返工率、积压时长及不同版式表现。记录业务周期波动和文件复杂度，避免只抽取容易样本。

## 候选方案与建议

比较人工录入、现有业务软件/OCR、模板与规则校验、模型辅助抽取。字段固定、版式稳定且校验规则明确时，先用表单校验、OCR与规则作为基线，避免为确定步骤引入生成模型。版式多样、文本表达变化大时，可测试识别/文档理解模型或多模态模型提取候选字段，再由规则校验格式、范围和交叉关系；模型仅标示字段、原文位置和待核状态。缺页、低质量、冲突、关键字段不确定及规则异常时转人工。规则可决定路由建议，但付款、资格、合同效力、拒绝、处罚或其他正式决定由有权限人员作出。技术选择参见[技术地图](../../01-tech-landscape/01-tech-map.md)、[提示/RAG/微调技术说明](../../01-tech-landscape/04-prompt-rag-finetune.md)及[应用地图](../../02-application-landscape/00-application-map.md#怎么使用这张地图)。

## 数据、权限与人工责任

确认文件来源、用途授权、字段必要性、个人/商业敏感信息、留存期限及是否需要遮蔽；限制样本、日志、供应商和模型可接触的内容。设置按岗位访问、传输与存储保护、日志最小化、删除/保留流程，并核验OCR/模型服务的数据处理条款及处理位置。保留原文件和页码/坐标定位，使复核者能核对字段证据。业务负责人批准字段定义和错误处置；数据/IT负责人维护接口及访问控制；一线审核人确认低置信、冲突和高影响字段；有权审批人员承担最终决定责任。建立改正记录、申诉/纠错路径及回退到人工流程。

## 风险门槛与控制

按[优先级方法](../06-prioritization.md)先审门槛。数据来源/用途、访问权限、必要字段、保留边界、责任人和人工纠错机制未确认时为“待补充”，不进入真实业务试点。若错误可能触发资金支付、个人权益影响或不可逆操作，而无法提供有效复核和暂停控制，则不通过或缩减为无影响的辅助任务。针对版式变化、缺失字段、相似名称、手写/低质扫描、恶意文档内容和异常值进行测试；关键字段不得静默自动通过，保留原文证据及字段级置信/待核标记。具体适用制度依地点、行业、数据类别和用途核查，不作普遍合规断言。

## 可测量效果与完整成本

| 维度 | 指标（试点前定义口径） | 当前基线/目标 |
|---|---|---|
| 质量 | 字段级准确率/召回率、关键字段漏检、规则异常检出、原文定位正确率 | 待测；目标由负责人预设 |
| 效率 | 每份处理时间、人工复核比例、返工率、积压时间 | 待测；目标由负责人预设 |
| 风险 | 高影响字段错误、越权访问、不同版式/语言误差差异、纠错时长 | 待测；门槛由组织设定 |
| 成本 | 每份成功处理全成本、异常件成本、持续维护成本 | 待测；按同一期间核算 |

完整成本包括字段与流程梳理、样本合法性审查/标注、扫描和清理、OCR/模型/软件许可与调用、系统集成、规则维护、人工复核和异常处置、存储与安全、评测和回归、培训、供应商管理、审计、故障恢复及退出迁移；将一次性和持续成本、内部工时分别列示。不得将减少的录入时间直接等同现金节省。

## 试点设计与决策

选取单一低影响、可回退文件类型；先用合成或脱敏样本验证字段映射与接口。门槛通过后，按来源、版式、质量和例外类型分层抽取经授权样本，由人工建立双人核对的参考答案；同一批样本比较人工/现有OCR规则与模型辅助方案，采用字段级评分并单列关键字段漏检、不同群体或语言表现、复核时间和全成本。启动前确定样本量、周期、阈值和错误升级办法；数值均**待测/待定**。试点只产生待审核记录，不触发付款、拒绝、资格、处罚或外部通知。

- **继续评估/扩围**：门槛持续通过，预设关键字段和质量阈值达到，错误均可发现/纠正，人工负担及完整成本可接受，业务所有者愿意承担维护。
- **修改后重测**：问题集中在可修复的字段定义、扫描质量、规则或少数版式，修正后以独立样本复测。
- **停止/回退**：关键字段漏检超过预设上限、错误不可追溯或影响无法控制、数据权限不成立，或成本/复核负担不合预期。

依[效果评估框架](../../06-evaluation/01-value-framework.md)固定基线和成本口径，风险审查参照[治理风险框架](../../08-governance/01-risk-framework.md)。

## 组织差异

企业可按供应商发票、订单或内部表单等流程衡量质量、周转和成本；政府/公共服务机构可评估材料归集和受理分流，但不得把抽取结果当作拒收或资格结论，并按具体业务核查数据和采购要求；事业单位应由专业人员确认文件语义、字段定义及专业审核边界；非营利组织可先比较现有表单工具和人工方案，并计入志愿者培训、交接及持续费用。组织类型不自动决定数据规则或风险等级。

## PPT 要点

- 先选一种文件和低影响流程，建立人工/OCR/规则基线。
- 字段抽取应带原文定位和待核状态；规则校验与人工审核承担不同职责。
- 用字段级质量、漏检、复核负担、周转、差异表现和全成本判断。
- 试点不自动作付款或资格等正式决定；按预设条件继续、修改或停止。

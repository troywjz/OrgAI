# 02 AI 应用全景

## 本章目标

本章回答"AI 在组织里落成哪几类应用形态"。技术是手段，应用形态是组织真正购买和使用的东西。本章把纷繁的 AI 产品归纳为九类应用形态，每类说明解决什么问题、带来哪类价值、依赖哪些技术、成熟度如何，帮助决策者在面对具体场景前先建立一张"能做什么"的地图。

## 主要读者

决策者、业务负责人。

## 不同组织类型的差异

- 企业：关注各应用形态对收入、成本和竞争优势的贡献。
- 【政府】智能客服、公文处理类内容生成、文档审核是常见切入点，需关注政务数据合规和输出内容的权威性要求。
- 【事业单位】需关注医疗、教育等领域应用的专业审核要求和公益属性。
- 【非营利】优先考虑能直接节省人力的知识问答和内容生成，并关注捐赠方对资金使用透明度的要求。

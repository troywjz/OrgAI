# 01 AI 技术全景

## 本章目标

本章回答"有哪些 AI 技术，各自能带来什么价值，为什么选这个不选那个"。读者读完后应能看懂供应商方案中的技术选型，能判断一项技术是否适合本组织的问题、数据和预算，并能就提示工程、RAG、微调、部署方式、自研与采购等关键选择做出决定。本章不讲技术实现细节。

## 主要读者

决策者、IT 负责人。

## 写作规则

每篇技术文档都使用 [templates/tech-card.md](../../templates/tech-card.md) 技术卡模板，按 [STYLE_GUIDE.md](../../STYLE_GUIDE.md) 第 1、2 节组织：一句话本质、现实价值、差异化对比、成本与门槛、成熟度与风险。

## 不同组织类型的差异

- 企业：技术选型以投入产出和竞争优势为主要依据。
- 【政府】应按实际用途、数据类别和适用要求核查采购、数据处理与部署约束，再确定技术选型。
- 【事业单位】需关注医疗、教育、科研数据的特殊合规要求，以及有限的 IT 人员能否维护所选技术。
- 【非营利】资金和技术人员有限，应优先考虑低门槛、按量付费、维护负担轻的技术。

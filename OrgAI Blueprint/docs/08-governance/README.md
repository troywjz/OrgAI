# 08 治理与合规

## 本章目标

本章回答"AI 的风险、安全、合规、伦理如何管控"。本章提供 AI 风险框架，覆盖数据安全与隐私、法规合规、伦理与公平、模型风险管理，并提供可直接改用的内部制度模板，帮助组织在推进 AI 应用的同时守住底线，并让决策者清楚哪些风险必须在立项前处理。

## 主要读者

决策者、法务、IT 负责人。

## 不同组织类型的差异

- 企业：需关注行业监管要求（如金融、医疗）和跨境业务的合规差异。
- 【政府】需关注政务数据合规、信创与国产化、网络安全等级保护，以及 AI 辅助决策的责任归属。
- 【事业单位】需关注医疗、教育、科研数据的特殊保护要求和伦理审查。
- 【非营利】需关注受助人群个人信息保护，以及向捐赠方披露 AI 使用情况的透明度要求。

# 06 效果评估

## 本章目标

本章回答“怎么衡量 AI 项目的 ROI 和业务效果，用什么工具”。本章提供多维价值评估框架、ROI 与 TCO 测算方法，并计划补充指标库、模型评估和公共价值工具。目标是在立项时明确基线和目标，之后按同一口径检验结果。

## 主要读者

决策者、财务、项目经理。

## 不同组织类型的差异

- 企业：以财务回报为主，同时关注运营和客户指标。
- 【政府】以服务效能和群众满意度为主，需关注绩效考核口径与财政资金使用评价要求。
- 【事业单位】需平衡公益属性与成本效益，关注评估结果与编制、考核的关系。
- 【非营利】需向捐赠方透明展示资金使用效果，评估方法应简单、可复核。

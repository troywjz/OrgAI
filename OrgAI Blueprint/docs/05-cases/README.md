# 05 案例

## 本章目标

本章回答"别人做成了什么、踩了什么坑"。本章收集公开可核实的组织 AI 应用案例，按统一格式记录背景、方案、技术选型、投入和结果，并提供按行业、组织类型、应用形态检索的索引，最后总结跨案例的共性经验，为场景选择和实施提供参照。

## 主要读者

所有读者。

## 写作规则

- 每个案例使用 [templates/case-card.md](../../templates/case-card.md) 案例卡模板。
- 案例来源必须公开可核实，并登记到 [references/sources.md](../../references/sources.md)。
- 不写入任何涉密信息、未公开的客户数据或个人信息；匿名化不能替代公开可核实的来源。
- 单个案例存放在本目录下的 `cases/` 子目录中，文件名格式为 `case-编号-简短英文描述.md`。该子目录在录入第一个案例时创建。

## 小节目录

| 编号 | 计划文件名 | 标题 | 写作要点 |
|---|---|---|---|
| 01 | 01-case-index.md | 案例索引 | 用表格列出全部案例，支持按行业、组织类型、应用形态检索。每行链接到 `cases/` 下的案例文件。 |

## 不同组织类型的差异

- 企业：公开案例相对较多，需注意区分供应商宣传材料和可核实的结果数据。
- 【政府】案例多见于官方公开报道，需注意结果指标的统计口径。
- 【事业单位】医院、学校等案例需避免录入个人信息，仅记录公开可核实且可适当引用的内容。
- 【非营利】公开案例较少，可补充国际组织的公开报告，并注明适用条件的差异。

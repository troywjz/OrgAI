# 00 总览

## 本章目标

本章告诉读者这套蓝图怎么读、先读哪里，并用一页纸讲清全书结论。本章还提供组织 AI 成熟度模型，帮助组织判断自己处在哪个阶段，从而决定后续章节的阅读重点和行动优先级。

## 主要读者

所有读者。决策者重点读执行摘要和成熟度模型；业务负责人、IT 负责人、项目经理按阅读指南选择路径。

## 不同组织类型的差异

- 企业：成熟度判断以业务收益和规模化程度为主要依据。
- 【政府】成熟度还需考虑信创与国产化要求、政务数据合规和预算周期对推进节奏的约束。
- 【事业单位】需关注编制与考核机制对推广阶段的影响。
- 【非营利】资金有限，成熟度路径可能长期停留在试点或推广阶段，需说明这样是否合理。

# 07 组织转型

## 本章目标

本章回答"人、流程、组织结构如何随 AI 调整"。单个 AI 项目上线不等于组织用好了 AI。本章覆盖 AI 战略制定、运营模式选择、流程再造、人才与技能、变革管理、文化与激励，并提供转型路线图模板，帮助组织从零散试点走向规模化应用。

## 主要读者

决策者、HR。

## 不同组织类型的差异

- 企业：转型可与组织结构调整、绩效考核改革同步推进。
- 【政府】需关注编制、职能设置和干部考核的约束，转型更多体现为流程优化和能力提升。
- 【事业单位】需关注编制与考核机制、专业人员的职业发展诉求。
- 【非营利】需考虑志愿者的 AI 素养培训和低成本的能力建设方式。

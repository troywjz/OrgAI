# OrgAI

面向企业与组织（含政府、事业单位、公共机构、非营利组织）的 AI 应用开源框架。

本项目是一个框架基础，不包含任何涉密信息或真实业务数据，以 [MIT 协议](LICENSE) 开源。

## 模块

| 模块 | 内容 | 状态 |
|---|---|---|
| [OrgAI Blueprint](OrgAI%20Blueprint/README.md) | AI 应用全景与应用策划：技术全景、应用全景、场景、实施部署、案例、效果评估、组织转型 | 建设中 |
| AI 技术研究 | 前沿技术跟踪与评测 | 规划中 |
| 大数据与数据治理 | 数据底座、数据质量、知识库构建 | 规划中 |
| 模型训练与领域微调 | 训练、微调、蒸馏的方法与脚手架 | 规划中 |
| 本地部署与推理优化 | 私有化部署、量化、推理服务 | 规划中 |
| 智能体应用 | Agent 框架、工具集成、工作流 | 规划中 |
| 组织 AI 战略 | 战略规划、治理与合规 | 规划中 |

后续模块与 Blueprint 并列放在仓库根目录下，各自独立维护。
